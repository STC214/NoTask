# 1.4.1 图标纠正与复审

## 第一轮：原图与生成链路

- 去掉上一版裁脸重绘的素材；`artwork/launcher-source.png` 与用户放在根目录的原图字节完全一致。
- 将完整 1792×1792 图片等比缩放到 512×512，仅添加 8% 半径圆角。没有局部裁切，没有生成式重绘。

- 打包脚本在构建前自动重建图标，避免源图更新后 APK 使用旧资源。
- 清理已无用途的图标资源、配色和旧说明；版本更新到 1.4.1 / 15。
- 原图副本 SHA-256 与根目录图片一致。全部不透明像素对完整原图等比缩放的平均 RGB 差值为 0.47，角部透明、四边中点不透明。
