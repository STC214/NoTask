## 逐轮发现与处理

1. **配置与作用域**：开关状态独立于注入作用域；首次请求前保存启用意图，避免页面重建后丢失；批准结果合并作用域查询结果，处理查询延迟；批准回调不再覆盖后续开关状态。
2. **运行时**：配置读取和任务更新串行到主线程；生命周期补读最新配置；页面前台不恢复可见；模块上下文异常不破坏原应用生命周期，原应用异常仍原样传播；单个任务失效不阻断其他任务更新。
3. **列表与遗留逻辑**：用 DiffUtil 发送精确列表更新，移除可能碰撞的包名哈希稳定 ID；移除旧后台计数器、旧模式控件和闲置样式。
4. **构建与兼容性**：移除不可移植的自定义 AAPT2 路径；更新稳定依赖；补齐 Android 8–11 和 Android 12+ 的备份规则；整理与最低 SDK 重复的资源目录限定符。
5. **最终复审**：对配置、Hook 调用链、页面销毁、列表排序/筛选/哈希碰撞和打包流程再次检查。自动化覆盖范围内未发现待修复问题。
