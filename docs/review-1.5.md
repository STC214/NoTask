# 1.5 三模式审查

- 每应用恢复返回键、后台模式，新增“直接隐藏”，三选一并独立持久化。应用开关仍为总开关。
- 使用新的配置命名空间，未配置时保持现有“直接隐藏”体验；切换模式时清除上一模式的隐藏触发状态。
- 所有任务状态与配置在主线程串行处理；后台延迟确认避免页面切换的瞬时 Pause 误触发，恢复前台、切换模式或关闭开关取消延迟任务。
- 返回事件保留原始调用链，不主动结束 Activity；返回判断基于任务根 Activity。自定义返回手势不进入被 Hook 的平台方法时，返回模式覆盖依赖应用实现。
- 配置切换、后台状态机、模式迁移默认值、异常传播和任务更新使用 JVM 单元测试验证。
- 时机模式只更新当前进程实际观察到的任务，避免仅运行服务的进程覆盖界面进程的隐藏状态；直接模式和关闭总开关仍更新全部应用任务。
- 保留亮暗主题、完整原图圆角图标及指定的正式发行证书；私钥仍被 Git 排除。
- 自动化测试使用 Mock Android 服务，不等同于全部厂商/Xposed 真机验证。首次注入及目标进程退出后的限制不变。

构建与校验使用 `scripts/package.ps1`，本地日志、补丁、快照和回滚脚本位于 `backup/three-modes/`。
