# 1.5.1 全量复审

## 第一轮：复现与修复

1. 原后台状态机把 `onPause` 当作后台。权限弹窗、透明窗口、分屏失焦时 Activity 仍可见，却会在 180ms 后隐藏。新增三个状态机回归用例在原源码上均失败。现按 started Activity 身份集合跟踪可见性，只有 `onStop/onDestroy` 后集合为空才确认后台；模式切换也使用同一判断。
2. 应用扫描期间任一 label/icon 读取异常会终止整个列表。新增卸载竞态用例在原源码上失败；现逐条隔离异常，继续加载其他应用。列表查询本身失败仍交给原有错误提示。

修复前复现：15 个测试中 4 个失败；修复后原有测试和新增用例全部通过。

## 第二轮：边界与界面复查

- 核对三种模式互斥、旧配置默认迁移、实时开关、任务归属过滤、配置监听和原调用链异常传播。
- 核对弹窗/分屏暂停、多 Activity 切换、旋转重建、前台恢复、延迟任务取消及模式切换；补充 Hook 的替换 Activity 和模式切换取消定时器测试。
- 核对列表搜索/排序、服务断连和作用域异步回调；保留首次注入需要重启目标应用的提示。
- 模拟器 200% 大字体复查发现副标题被固定高度裁切、模式名称被省略。标题改为自适应高度；模式按钮支持换行并保持组内等高、最小 48dp。

## 第三轮：修复后全链路验证

- 52 项 JVM 测试通过，Debug 与 Release Lint 均无问题；构建两个变体并验证压缩后入口、ZIP 完整性、16KB 对齐及既定证书指纹。
- 模拟器检查三按钮默认单选、亮色/暗色/跟随系统、进程重启持久化、搜索和大字体。模拟器启动曾出现 System UI 无响应弹窗，关闭系统弹窗后重跑。
- 核对原图仍为完整等比缩放加圆角，发行证书身份未改变；私钥仍留在项目 signing 目录但不进入仓库。
- 最终复审在上述检查范围内未发现新的待修问题。自动化 Android 服务使用 mock；模拟器未安装 Xposed，实际注入和厂商桌面行为仍需在相应设备验证。自定义预测返回绕过平台 Hook 的边界与 1.5 相同。
