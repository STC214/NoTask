# 发行签名约定

2026-10-20 起，采用现有 APK 的签名证书作为项目正式发行身份，不重新生成或轮换证书。

- 正式包名：`NoTask-版本-release.apk`，使用 R8 优化的 Release 构建。
- 公共 SHA-256 指纹：`config/release-certificate.sha256`。仅此公有指纹进入仓库。
- 默认私钥：项目内的 `signing/notask-release.keystore`；可设置 `NOTASK_RELEASE_KEYSTORE`。
- `signing/`、`*.keystore`、`*.jks`、`*.p12`、`*.pfx` 已被 Git 排除。提交前核对忽略规则与暂存区，私钥不上传。
- 别名和密码沿用当前密钥的既有配置。请离线备份私钥，避免其他项目共享或覆盖该文件。
- 证书原主题包含 `Android Debug`，指定为发行身份不会改变它；现有安装包和后续发行包使用同一证书。
- 打包要求密钥存在，并在签名后核对证书指纹；没有自动生成新发行密钥的后备路径。

此前审查报告中的“测试签名”描述保留为历史记录，当前发行约定以此文档为准。
