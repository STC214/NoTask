## 1.5 三种隐藏方式

每个应用提供三个互斥选项，应用开关是总开关，模式可以分别保存：

- **返回键隐藏**：任务根 Activity 收到返回事件时隐藏；重新开始或进入前台时恢复可见，不消费原有返回事件。
- **进入后台隐藏**：全部 Activity 停止可见后短暂确认（180ms）再隐藏，避免页面切换误触发；再次进入前台恢复可见。
- **直接隐藏**：开启应用开关后立即隐藏，在前台也保持隐藏；关闭开关恢复可见。

切换模式会实时重新计算已有任务的可见性。1.4 已有配置默认保持“直接隐藏”；不自动读取废弃的 1.2 时机配置。首次注入和目标进程未运行的限制仍然适用。

升级到 1.5 后，请重启目标应用一次以加载新增 Hook；此后模式切换通过远程配置实时生效。

## 隐藏逻辑

- “直接隐藏”模式：打开应用开关后立即隐藏已有任务，不等待返回键或进入后台，重新进入前台仍保持隐藏。
- 关闭开关：立即恢复已有任务的可见性。保留注入作用域，使后续切换仍可实时生效。
- 旧时机配置不再使用，新的三选一配置按应用独立保存。

## 使用与边界

1. 在支持 Modern Xposed API 101/102 的框架中启用模块。
2. 打开 NoTask，启用目标应用并批准首次作用域请求。
3. **首次加入作用域时，已运行的目标进程需要重启一次以加载模块。** 尚未加载模块的进程不会接收配置变更。
4. 模块已加载后，开关通过 Remote Preferences 实时更新已有任务，无需返回键、切后台或再次重启。
5. 关闭开关仅停止隐藏，不移除注入作用域。若要彻底移除注入，请在框架管理器移除作用域并重启目标应用。

仅改变系统任务的 exclude-from-recents 标志。系统/桌面的任务列表缓存和厂商实现可能影响实际刷新时机；需在真机验证。

## 构建

Android 8.0+，Java 17+，Android SDK 37。标准 Android SDK 环境使用 `gradlew testDebugUnitTest assembleDebug`。

Windows 下可运行 `powershell -File scripts/package.ps1`，执行单元测试、Debug/Release Lint、双版本构建、16 KB ZIP 对齐、签名与压缩后模块入口检查。输出位于 `dist/`，附带 SHA-256 校验值。

`NoTask-版本-release.apk` 为正式发行包，沿用已分发版本的现有证书，签名身份不变。证书公开指纹固定在 `config/release-certificate.sha256`，打包后会核对，避免误换密钥造成升级冲突。

发行私钥保存在项目的 `signing/notask-release.keystore`，也可通过 `NOTASK_RELEASE_KEYSTORE` 指定路径。`signing/` 和常见密钥扩展名已加入 Git 排除；请另行离线备份。私钥不进入 Git，缺失时打包会报错，不会自动生成新发行身份。此证书来源于先前的 Android Debug 证书，现指定为本项目发行身份，其证书主题及指纹保持原样。
